# ChatGPT (GPT personalizado)

No hay instalador: ChatGPT web no lee archivos del repo. Se copia a mano.

1. ChatGPT → **Explore GPTs → Create → Configure**.
2. **Instructions**: pega `instrucciones.md` (5,061 caracteres; el límite es 8 000).
3. **Description**: `descripcion.txt`. **Conversation starters**: una línea de `starters.txt` por casilla.
4. **Knowledge**: sube los archivos de `knowledge/`.
5. Para Codex (CLI o extensión) usa `agents/codex/`, no esta carpeta.
