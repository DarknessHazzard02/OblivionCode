
## Uso dentro de un Data Pipeline (con correo de resultados)
# 1. **Actividad Notebook** (ej. nombre `Cargar ZMM_MD04`): apunta a este notebook.
   Los parámetros de la celda de parámetros se pueden sobreescribir en
   Settings → Base parameters (ej. `target_table`, `write_mode`).
2. **Actividad Office 365 Outlook** conectada al *On success* del notebook:
   - **Subject** (contenido dinámico):
     `@concat('ZMM_MD04: ', if(contains(activity('Cargar ZMM_MD04').output.result.exitValue, '"status_global": "OK"'), 'Carga exitosa', 'Revisar carga'))`
   - **Body**:
     `@activity('Cargar ZMM_MD04').output.result.exitValue`
     (el JSON del resumen: archivos procesados, filas, rechazadas, negativos, errores)
3. **Segunda actividad Outlook** conectada al *On failure* del notebook, por si el
   notebook truena antes de llegar al exit (ej. sin acceso al Lakehouse):
   - **Body**: `@activity('Cargar ZMM_MD04').error.message`
4. Encadena el **Copy Job** (ingesta del share a OneLake) antes del notebook y
   programa el pipeline con Schedule. Con modo "history", si el pipeline no corre
   por varios días, la siguiente corrida carga automáticamente los días faltantes.
