# Personal Portfolio

Portfolio page with a welcome section, project tiles and contact links. Project tiles link to other exercises in this repo, so serve the repo root for the links to work.

Source: freeCodeCamp, Responsive Web Design certification.

## Files

| File | Language | Purpose |
|---|---|---|
| `Personal_Portfolio.html` | HTML | Page markup |
| `Personal_Portfolio.css` | CSS | Page styles, linked from the HTML |

## How to run

Open `Personal_Portfolio.html` in a browser, or serve the repo locally:

```bash
"C:/Program Files/Python315/python.exe" -m http.server 8765 --bind 127.0.0.1
```

Then go to <http://127.0.0.1:8765/Main_Dev_Projects/Personal_Portfolio/Personal_Portfolio.html>.
