# Odin Tic Tac Toe

Two-player Tic Tac Toe with names, win and tie detection and a highlighted winning line. `Gameboard`, `GameController` and `DisplayController` are single modules (IIFE), players come from a factory, and the game logic never touches the DOM.

Source: The Odin Project, Full Stack JavaScript path.

## Files

| File | Language | Purpose |
|---|---|---|
| `index.html` | HTML | Name form, status, board |
| `styles.css` | CSS | Dark theme, 3x3 grid |
| `app.js` | JavaScript | Module pattern and factory functions |

## How to run

From the repo root (ES modules do not load from `file://`):

```bash
"C:/Program Files/Python315/python.exe" -m http.server 8765 --bind 127.0.0.1
```

Then open <http://127.0.0.1:8765/Main_Dev_Projects/Odin_Tic_Tac_Toe/index.html>.
