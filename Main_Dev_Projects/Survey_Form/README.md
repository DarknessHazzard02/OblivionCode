# Survey Form

Survey form with text, select, radio, checkbox and textarea inputs.

Source: freeCodeCamp, Responsive Web Design certification.

## Files

| File | Language | Purpose |
|---|---|---|
| `Survey_Form.html` | HTML | Page markup |
| `Survey_Form.css` | CSS | Page styles, linked from the HTML |

## How to run

Open `Survey_Form.html` in a browser, or serve the repo locally:

```bash
"C:/Program Files/Python315/python.exe" -m http.server 8765 --bind 127.0.0.1
```

Then go to <http://127.0.0.1:8765/Main_Dev_Projects/Survey_Form/Survey_Form.html>.
