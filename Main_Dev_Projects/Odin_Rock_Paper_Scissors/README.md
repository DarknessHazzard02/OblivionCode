# Odin Rock Paper Scissors

Rock Paper Scissors against the computer with buttons, a running score and a winner at 5 points.

Source: The Odin Project, Foundations path.

## Files

| File | Language | Purpose |
|---|---|---|
| `index.html` | HTML | Score board, move buttons and result text |
| `styles.css` | CSS | Dark theme |
| `script.js` | JavaScript | Pure game functions (`getComputerChoice`, `playRound`) plus DOM wiring |

## How to run

Open `index.html` in a browser. No build step and no dependencies.
