# Odin Sign-up Form

A two-column sign-up form with native HTML validation, visible valid and invalid states, and a password match check. Nothing is sent anywhere.

Source: The Odin Project, Foundations path.

## Files

| File | Language | Purpose |
|---|---|---|
| `index.html` | HTML | Form markup with `required`, `type`, `pattern` and `minlength` |
| `styles.css` | CSS | Dark theme, `:invalid` / `:valid` states shown only after a field is touched |
| `script.js` | JavaScript | Password match via `setCustomValidity`, local-only submit |

## How to run

Open `index.html` in a browser. No build step and no dependencies.
