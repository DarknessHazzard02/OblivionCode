# Odin Etch-a-Sketch

A hover-to-draw grid. The grid size can be changed (1 to 100 per side), and rainbow mode paints a new random color on each pass and makes the square 10% more opaque each time.

Source: The Odin Project, Foundations path.

## Files

| File | Language | Purpose |
|---|---|---|
| `index.html` | HTML | Toolbar and grid container |
| `styles.css` | CSS | Fixed square board filled by Flexbox rows |
| `script.js` | JavaScript | Builds the grid, one delegated hover listener, input validation for the size |

## How to run

Open `index.html` in a browser. No build step and no dependencies.
