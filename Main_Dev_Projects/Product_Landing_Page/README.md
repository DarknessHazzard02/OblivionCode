# Product Landing Page

Product landing page with a header nav, embedded video, pricing and an email form.

Source: freeCodeCamp, Responsive Web Design certification.

## Files

| File | Language | Purpose |
|---|---|---|
| `Product_Landing_Page.html` | HTML | Page markup |
| `Product_Landing_Page.css` | CSS | Page styles, linked from the HTML |

## How to run

Open `Product_Landing_Page.html` in a browser, or serve the repo locally:

```bash
"C:/Program Files/Python315/python.exe" -m http.server 8765 --bind 127.0.0.1
```

Then go to <http://127.0.0.1:8765/Main_Dev_Projects/Product_Landing_Page/Product_Landing_Page.html>.
