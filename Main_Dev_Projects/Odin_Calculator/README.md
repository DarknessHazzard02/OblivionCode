# Odin Calculator

An on-screen calculator that evaluates one pair of numbers at a time, left to right (12 + 7 - 1 = 18), with decimals, backspace, keyboard support and a message for division by zero.

Source: The Odin Project, Foundations path.

## Files

| File | Language | Purpose |
|---|---|---|
| `index.html` | HTML | Display and keypad |
| `styles.css` | CSS | Dark theme, CSS grid keypad |
| `script.js` | JavaScript | `add`, `subtract`, `multiply`, `divide`, `operate` and the input state machine |

## How to run

Open `index.html` in a browser. No build step and no dependencies.
