# Odin Landing Page

A landing page for a fictional data-pipeline product, laid out with Flexbox only.

Source: The Odin Project, Foundations path.

## Files

| File | Language | Purpose |
|---|---|---|
| `index.html` | HTML | Header, hero, feature cards, quote and call to action |
| `styles.css` | CSS | Dark theme and Flexbox layout, stacks on narrow screens |

## How to run

Open `index.html` in a browser. No build step and no dependencies.
