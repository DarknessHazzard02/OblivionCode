# The Odin Project - JavaScript

Computer Science exercises from the Full Stack JavaScript path. Each file runs on its own with node, checks itself with `node:assert` and prints a short demo.

| File | Exercise |
|---|---|
| `Recursion.js` | `fibs`, `fibsRec`, `mergeSort` |
| `Linked_List.js` | Singly linked list with `append`, `prepend`, `at`, `pop`, `find`, `toString`, `insertAt`, `removeAt` |
| `HashMap.js` | Hash map with separate chaining that doubles its capacity past the load factor |
| `Binary_Search_Tree.js` | Balanced BST: insert, delete, find, level and depth-first traversals, height, depth, rebalance |
| `Knights_Travails.js` | Shortest knight path on an 8x8 board with breadth-first search |

The browser projects of this path (Library, Tic Tac Toe, Restaurant Page, Todo List, Weather App, Battleship) mix HTML, CSS and JavaScript, so they live in `Main_Dev_Projects/Odin_*`.

## How to run

```bash
node Recursion.js
```

Each file prints `all checks passed` when its assertions hold.
