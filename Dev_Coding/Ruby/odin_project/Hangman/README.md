# Hangman

Guess a random 5-12 letter word from `words.txt` with up to 7 misses. Type `save` to store the game in `saves/<name>.json`; at the next start you can load it. Save names are restricted to letters, digits, `_` and `-`, and a broken save file shows a message and starts a new game.

Source: The Odin Project, Ruby path.

> **Not run yet.** Ruby is not installed on the machine where this was written, so the code was checked by reading only. Each file has a self-check; run it before trusting the code.

## How to run

```bash
ruby hangman.rb
ruby hangman.rb --check
```
