# Connect Four

Two-player Connect Four in the terminal, written test-first. `lib/connect_four.rb` keeps the board rules apart from input and output, so the RSpec file tests drops, full columns, all four win directions and the game loop with fake input.

Source: The Odin Project, Ruby path.

> **Not run yet.** Ruby is not installed on the machine where this was written, so the code was checked by reading only. The RSpec file is the check: run it before trusting the code.

## How to run

```bash
ruby main.rb
rspec spec/connect_four_spec.rb
```
