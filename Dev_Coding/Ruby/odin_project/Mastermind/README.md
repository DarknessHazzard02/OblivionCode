# Mastermind

Guess a 4-digit code (digits 1-6) in 12 turns, or set a code and watch the computer break it. The computer keeps only the codes that match every answer so far, so it solves any code in a handful of turns.

Source: The Odin Project, Ruby path.

> **Not run yet.** Ruby is not installed on the machine where this was written, so the code was checked by reading only. Each file has a self-check; run it before trusting the code.

## How to run

```bash
ruby mastermind.rb
ruby mastermind.rb --check
```
