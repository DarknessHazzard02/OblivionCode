# Odin Recipes

The Odin Project, Foundations: the first project, a small multi-page site built with **HTML only** (CSS is not part of this exercise).

| File | Purpose |
|---|---|
| `index.html` | Home page with links to each recipe |
| `recipes/*.html` | One page per recipe: description, ingredients list, ordered steps |

**Run it:** open `index.html` in a browser.
