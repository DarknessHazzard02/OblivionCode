Introduction

Bash is a Unix shell and command language. A script is a plain text file with a list of commands that run in order.

Every script starts with a shebang that tells the system which interpreter to use:

#!/bin/bash
  • Make it executable with chmod +x script.sh.
  • Run it with ./script.sh.
Variables

Variables are assigned without spaces around the equals sign and read with a dollar sign.

NAME="Haz" echo "Hello, $NAME"

Command output can be stored with command substitution:

TODAY=$(date +%F)
Conditionals

Use [[ ]] for string and file tests and (( )) for arithmetic.

if [[ -f config.txt ]] then echo "Config found" elif (( COUNT > 10 )) then echo "Too many" else echo "Nothing to do" fi
  • -f file exists
  • -z string is empty
  • =~ regex match
Loops

Bash supports for, while and until loops.

for (( i = 1; i <= 3; i++ )) do echo "Pass $i" done

An until loop runs while its condition is false, which is handy for input validation.

Functions

Functions group commands and read arguments as $1, $2 and so on.

GREET() { echo "Hi, $1" } GREET "camper"

Return a status with return and data with echo.
